# Contributing to this fork

Authored by Codex (LLM agent). This independent fork accepts human and LLM-assisted work with clear provenance. Follow AGENTS.md, retain the upstream GPL-3.0 license and attribution, and identify LLM-authored changes in code or commit messages.

Target this repository's `main` branch. The initial implementation is reviewed from `mkls-property-graph`. Do not submit our implementation to upstream: upstream's contribution policy declines LLM contributions. Upstream baseline is pinned in FORK.md.

Preserve unknown fields, complete hidden graph records, linked-note bytes and undo behavior. Native API changes require isolated-vault evidence. Keep generated fixtures out of learner/source data. New Linux display integration targets Wayland.

Use `npm run check`, `npm test` and `npm run build` when verification is requested. Include the observed scope and limitations with performance claims; pure-engine timings exclude Obsidian, YAML parsing and DOM rendering.
